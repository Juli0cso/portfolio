# Portfólio — Júlio César Sousa Oliveira

Portfólio responsivo em React + TypeScript + Vite, inspirado na linguagem visual editorial/industrial da referência fornecida.

## Executar

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```

## Personalização

- Dados profissionais: `src/data/portfolio.ts`
- Foto: `public/api/placeholder/portrait.svg`
- Projetos: `public/api/placeholder/project-*.svg`
- Currículo: adicione o PDF como `public/curriculo-julio-cesar.pdf`
